# 批混剪工作室 - 安装包

批混剪工作室 v3 的安装包构建项目。

## 下载

直接下载 `批混剪工作室_安装器.exe`，双击运行即可安装。

## 从源码构建

### 环境要求

- Python 3.10+
- PyInstaller: `pip install pyinstaller`
- FFmpeg（放到 `ffmpeg/` 目录下）

### 构建步骤

```bash
python build.py
```

构建完成后，安装器位于 `dist/批混剪工作室_安装器.exe`。

## 安装器功能

- 选择安装路径
- 自动创建桌面快捷方式
- 自动创建开始菜单快捷方式
- 自动创建工作文件夹（片头、片中、片尾、背景、背景音乐、字幕、输出目录）
